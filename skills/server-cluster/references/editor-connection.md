# 按需使用 VS Code Remote SSH

读取时机：用户要在 VS Code 中查看或编辑远端代码，或终端 SSH 正常而编辑器连接异常。普通 SSH 查询、训练监控不要求启动编辑器。

## 打开正确目标

1. 使用 **Remote-SSH: Connect to Host…** 选择已核对的同一 SSH 别名。
2. 用 **Open Folder** 打开项目登记的远端绝对路径，核对身份、仓库根、分支与现有修改。
3. 沿用本技能默认的本地项目对话与知识维护方式；远端编辑器负责对应代码。核对实际 Agent 后端及 cwd，不只看窗口标题。若实际执行位置与既定工作方式不同，先说明并按用户／项目约定处理，不自动移动 Skill、切换项目或覆盖远端规则。

## 连接异常

- 查看 Remote-SSH 输出及必要登录终端，先判断是否等待密码、口令或 MFA，或已经进入远端组件启动阶段。
- 对比终端与 VS Code 使用的 SSH 程序、配置文件、别名、认证代理和转发条件。终端成功不保证另一客户端使用相同配置。
- 若涉及转发失败、远端组件、磁盘或权限问题，先记录对应证据。修改 SSH 设置、服务器配置，或执行 Kill／Uninstall VS Code Server 等动作前，须确认授权与对在用会话的影响，不作为默认修复。
- 项目未使用 VS Code 时，不把这些 UI 步骤强加给其他编辑方式。

依据：[VS Code 官方远端排障说明](https://code.visualstudio.com/docs/remote/troubleshooting)。只采用与当前症状相符的检查，不照单执行文档中的环境修改命令。
