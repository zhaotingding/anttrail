# 私有主机表模板

本文给出表的结构与**虚构示例**。把真实主机登记在你指定的、仅本机可读的独立文件里，例如用户目录的 `.anttrail/hosts.local.md`。在自己的本地约定中注明该文件的位置。没有登记时，先询问目标别名或请使用者提供对应行。写表前明确文件、字段与授权，复核最新内容。

| SSH 别名及角色 | 登录与连接 | 工作区、存储与硬件事实 | 外网及依赖来源 | 核验记录 |
| --- | --- | --- | --- | --- |
| `lab-example`（虚构容器别名） | 以本机 OpenSSH 配置解析。宿主关系未核实 | 项目根、真实挂载、GPU 型号、卡数及单卡容量均未核实 | 未核实 | 模板，无实机核验 |
| `compute-example`（虚构宿主别名） | 以本机 OpenSSH 配置解析 | 项目根及与上一别名是否共用物理机未核实 | 未核实 | 模板，无实机核验 |

按字段写下日期、证据和状态。别名只能定位一项配置，不能凭命名断定容器与宿主共用资源。静态记录可包含核实过的硬件形态、磁盘及解释器。GPU 占用、空闲空间、任务锁和网络可达性在任务开始时按需读取。

## 可直接使用的只读操作

- 本地核对 `ssh -G <实际别名>` 的有效 User、HostName、Port 和 IdentityFile。OpenSSH 配置可包含自定义动作，先确认使用的是预期配置。报告只取本次需要的字段。
- 获准连接后，用 `hostname`、`id -un` 和 `pwd` 核对远端身份。Linux 目标可按需用 `realpath`、`findmnt -T <项目路径>`、`df -h <项目路径>` 对照实际工作区与挂载。
- GPU 任务可按授权查询 `nvidia-smi -L` 与当时的进程和显存。设备存在、进程可见、资源获准使用是三个判断。
- 认证由用户已有的 SSH 程序、配置和代理承担。只记录非敏感定位结果，私钥、口令和令牌留在其凭据系统中。
