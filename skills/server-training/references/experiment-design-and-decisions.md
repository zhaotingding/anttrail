## 先定义能改变决策的实验

每项实验关联一个主要问题：验证实现、区分机制、复现基线、估计稳健性或确认性能。写明假设、实际干预、比较对象、主要指标、最小有意义收益、训练与搜索预算、选择规则及停止条件。规模小不自动意味着有效，规模大也不能弥补无判别力的设计。

先复用经核对的可比基线；需要重建时先验证关键链路。按风险选择少量数据或短程运行检查数据、目标、更新和评估是否正确，但低保真结果只支持对应阶段的判断，不能直接代替正式比较。

对照应能够区分候选机制与额外容量、数据、训练时间、优化器或实现差异等解释。有交互的联合机制可以联合实现，再按可辨识性安排消融；不把“每次只改一个数”或固定两组对照当作科学设计的全部。

机制归因必须核对代码实际实现的干预。[Tucker 等人的 RL 研究](https://proceedings.mlr.press/v80/tucker18a.html)展示了实现差异如何改变对方法收益的解释。方法复杂并不意味着贡献更强；可解释的简单改动也可能具有研究价值。

## 两层循环

- 内层执行：实现或配置 → 有效性检查 → 获批运行 → 聚合结果 → 更新该假设。
- 外层研究：综合多个实验和失败模式 → 复核解释与近邻文献 → 深化、拓展、转向或收尾。
- 外层触发依据是新证据、关键预测失败、共同误差或收益停滞，不机械规定每多少次实验重开一次脑暴。内外层都受原批准研究范围、预算与停止条件约束。[autoresearch 的循环结构](https://github.com/Orchestra-Research/AI-Research-SKILLs/blob/773a52944ba4747a18bd4ae9ade53fff041adcbc/0-autoresearch-skill/SKILL.md)可借鉴，其不询问授权和无界运行要求不采用。

## 先判有效性，再判科研假设

| 证据状态 | 判断 | 下一步 |
| --- | --- | --- |
| 数据、实现、评估或运行出错，干预未生效 | 执行／实现无效，不是方向反证 | 修复对应问题，隔离失效结果，判断是否仍在原授权内 |
| 短跑未充分学习，运行数少，效应区间同时容许收益与损失 | 证据不足 | 选择最有信息价值的补证据；预算不足则保留未决状态 |
| 某个配置未见提升 | 该配置、任务和预算下未观察到收益 | 检查训练充分性和机制预测，不扩大成整个方法族无效 |
| 有效比较对有意义收益给出足够精度的否定证据 | 可降低该条件下方向的优先级或停止 | 记录效应界限、条件和重新开启依据 |
| 关键机制预测在有效判别对照下失败 | 对相应机制构成反证或削弱 | 排查辅助假设，转向更能解释观察的候选 |
| 效应、机制迹象与关键对照一致 | 获得有限支持 | 扩大验证条件，检查边界、稳健性、规模与成本 |
| 只是预算耗尽或收益／成本不合算 | 资源决策，不等同科学证伪 | 标记预算停止或低优先级，不篡改科学结论 |

“没有显著差异”不能自动解释为“没有有用效果”。有意义效应及精度应结合问题界定；不要为所有 ML 指标机械规定同一种检验或固定 seed 数。[Lakens 的等效性讨论](https://pmc.ncbi.nlm.nih.gov/articles/PMC5502906/)

## 搜索、重复与停止

新批次启动前，将下面与本次问题有关的条件填入现有实验计划。具体数值由项目证据、成本和用户授权确定；缺少足以约束执行的资源上限时，先明确上限，不靠通用默认值代替。

| 条件 | 启动前应明确 | 命中后的动作 |
| --- | --- | --- |
| 硬资源上限 | 本批次允许的运行数、时长、GPU-hours 或费用中实际适用的上限，以及停止／保存方式 | 按已批准方式结束资源投入，不追加运行或超额重试；标记预算停止，不能据此宣称方向被证伪 |
| 有效试验条件 | 实现与干预检查、数据／评估约定、判断该问题所需的最低训练暴露或完成条件 | 不满足时标无效或未决，先修复或补证据；不将其计作方法失败 |
| 有意义效应与精度 | 主要指标、最小值得继续投入的效应、所需不确定性精度或机制预测 | 仅在有效证据足以支持判断时深化、降低优先级或淘汰；区间过宽时保留未决 |
| 复盘节点 | 已批准的阶段结束、关键判别对照完成、反常结果／机制预测失败，或约定的资源检查点 | 暂停无依据追加，综合结果并给出继续、补证据、转向或停止的理由 |

复盘触发不等于必须淘汰方向。项目可以约定有效试验数量或预算进度作为复盘节点，但不把“连续两次无提升”或“消耗一半预算”规定为所有方法通用的科学停止阈值。

- 多 seed 是估计不确定性的工具；区分调参用 seed 与独立确认用 seed，不通过删掉失败 seed 或只保留最优 run 制造收益。
- HPO 必须有合理搜索空间、预算和选择依据。新方法与基线需要可比调优机会，公平不意味着强制同一学习率。改变搜索空间或指标后，说明它属于新的探索步骤。[Eimer 等](https://proceedings.mlr.press/v202/eimer23a.html)
- 短程早停或资源分配策略要考虑不同方法的学习曲线，避免系统性淘汰慢热方法。技术故障停止与科学方向停止分别记录。
- 预定停止条件达到后不以“再试一个 seed”无限延长。允许在已授权策略范围内调整；扩大范围、资源或协议需重新确认。

## 持续更新研究判断

每轮收尾在现有记录中追加：假设 ID、实际运行与版本、主要变化、有效性、结果与不确定性、竞争解释、决策、下一个判别动作、重新开启条件。保留失败和不利结果，纠正旧结论时说明新证据，不抹掉历史。

方向不再有解释力时主动拓展文献与机制，不只是重置参数；方向得到支持时先增强证据再堆模块。项目长期知识只沉淀经过限定的结论，不把一次结果变成通用规则。[EvoScientist 的历史经验与挑战—机制映射](https://github.com/EvoScientist/EvoSkills/blob/4889c2270af5f9a7658bb6a6709bf37040902006/skills/research-ideation/SKILL.md)
