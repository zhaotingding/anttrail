# HTML 知识可视化与学习设计

## 目标与分工

- 生成高知识密度、视觉表达充分、方便自主学习的 HTML。主要版面应承载有用的概念、关系、证据、例子或决策，减少空泛铺垫、重复总结、大面积空白装饰与无意义卡片。
- 高密度通过组织、对照、图解和按需展开实现，不靠缩小文字、塞满首屏或省略关键推理。可视化讲解不能只把长文装进卡片；优先让核心难点在图形、表格或可操作状态中显现。
- 用户／项目明确风格优先；没有特别约定时默认柔和深色背景、浅色文字，避免大片纯黑纯白。保持阅读对比和图表辨识，不以炫酷、动画数量或组件数量自证有效。
- 科研判断与实验有效性沿用已有研究流程和证据，本技能负责忠实呈现与解释；实际功能开发结合 `code-development`。只有当前环境确有相应技能且任务需要时，才委托研究报告或长图导出等专门流程，不假定某个未发现的技能可用。
- 只沉淀有证据且可复用的项目约束；用户的文字删改优先，不把临时布局、配色或互动形式推广为通用规则。

## 从材料到学习页面

1. 明确读者基础、当前问题、材料边界与应学会的判断或操作。列出最短的必要前置知识链；缺少概念时给速查或补充入口，不默认从零讲起。
2. 生成前确定内容大纲、每部分要回答的问题、适合的视觉表示及必要交互。是否先展示并等待确认，遵循当前任务授权；已获授权且目标清楚时直接实现，不额外增加审批轮次。
3. 先给概览和主线，再呈现核心推理、例子及按需细节。标题表达问题或结论，图与解释就近，术语和来源可回查；复杂页面提供目录或必要搜索，避免读者靠遍历卡片找答案。
4. 重要机制按需要组织“问题或预测 → 示例／操作 → 结果与解释 → 理解检查／小结”。自测围绕预测、比较、解释、纠错或迁移，不仅考术语记忆；数量随目标确定，答案可按需展开，读者可以跳过。数据报告不机械套固定题数。
5. 复杂过程由学习者控制节奏，支持必要的逐步查看、暂停、回退、重置及直接跳转。不要强制点完每页、等动画播完或答对题才能继续；已掌握内容可以跳读。

## 图形与交互判据

- 先识别要表达的关系，再选择形式：结构用层级／关系图，差异用并置对照，顺序与状态用流程／步骤轨迹，数量用有明确尺度的图表。静态表示已经清楚时不强制动画；需要观察变化时采用受控交互。
- 讲解现有软件界面或截图时，优先采用用户提供或获准采集的真实截图，叠加编号标记，并与编号列表和逐项讲解联动。让读者直接看清位置、作用、操作反馈和容易混淆之处；不以抽象框图或重绘界面替代已有清晰截图，不把截图状态当作当前实时事实。
- 每项核心视觉应帮助解释、判别或定位信息；不能说明其作用的装饰应删减。多个视图保留一致符号、颜色含义和比较基准，图形不能成为文字之外另一套需要猜测的编码。
- 每个控件对应一个具体问题：改变什么、什么保持不变、输出怎样变化、原因与限制是什么。输入、当前状态、文字、图形与数值同步；已提供的前进、回退、暂停、继续和重置语义一致。
- 关键说明不只放在悬停提示里；关键控件有可理解名称、可见焦点和键盘操作路径。颜色之外保留标签或形状区分；非必要动态可减少或关闭，重要过程仍有可阅读的状态。
- 教学动画可以简化，但要说明简化条件；表示时间、因果或数据变化时保持真实含义，不能用箭头、运动或平滑制造未经证明的关系。

## 内容真实与实现

- 忠实于论文、教材或数据时先核对实际材料及版本；材料不足则说明缺口，不补造原文。明确区分来源结论、作者解释、自行构造的例子、真实计算、预设数据和示意动画。
- 数学与算法定义必要符号、单位、张量形状及关键步骤。图表标清样本／运行数量、指标和处理方法，保留相关不确定性、失败与缺失信息，不为好看挑选有利结果。
- 优先沿用已有技术，新建本地页面按需求使用直接的 HTML/CSS/JavaScript；不默认引入后端、框架、构建链或在线 CDN。确有需要的库、公式引擎和媒体应有明确用途，不能把验证工具误当交付依赖。
- 默认核心学习路径可离线使用，必要视频、动态图、字体和脚本随附本地资源；仅在用户明确允许时提供在线扩展，并标清离线边界。按要求选择单文件或本地资源包，不用字数或控件数量机械决定。
- 用户要求独立新设计或 clean-room 时重新决定构图、配色、版式和命名；不复用旧作品后只换文件名，也不把本次作品的布局变成以后必用模板。
- 代码与 Git 操作按项目及 `code-development` 的相应规则执行，未经授权不 push。

## 验证与交付

- 按[交付与验证](references/delivery-and-validation.md)检查内容、学习路径、真实浏览器操作及目标打开方式；局部修改只检查相关行为和直接影响，必要检查通过后交付。
- 交付可定位的 HTML 入口、必要资源、使用方式、实际检查及未验证部分。不同验证不能互相冒充，工具限制如实说明且不绕过；不把页面可读或模型自评当作真实学习效果。
