# 数据、论文、数学与证据表达

适用：实验数据页、论文导读、研究报告、公式和算法讲解。核心结论先由可靠材料和分析支撑，再设计呈现方式。

## 来源与科学结论

- 对论文、教材和代码记录实际来源及版本；没有取得完整方法或数据时标明缺口，不根据摘要补造细节。额外类比、推导和例子单独说明。
- 区分原文主张、实际测量、计算结果、作者推测和教学示意。论文中的领先结果不自动等于当前最新 SOTA，也不自动适用于另一任务或协议。
- 主页面能从结论追到图表、分析条件和原始依据；不必每屏堆完整文献表，但不能让证据入口消失。

## 实验数据与图表

| 项目 | 展示或核对内容 |
| --- | --- |
| 数据身份 | 数据版本、运行／配置、采样单位、有效与失败运行；不把模拟值标为实测 |
| 数量含义 | 指标名称、方向、单位、样本或运行数；区间具体表示什么 |
| 数据处理 | 聚合、平滑、筛选、缺失处理及轴变换；重要时可查看原始值 |
| 公平比较 | 数据划分、预算、模型选择和影响结论的条件；不能只并排显示一个最佳分数 |
| 交互筛选 | 当前条件和保留数量可见；筛选结果不能默认为完整总体 |
| 不确定性 | 区间、波动、失败和未决证据有位置；不靠视觉效果制造稳定或显著 |

统计、排序和派生指标用程序计算并核对。选择能回答问题的图，而非默认每项数据都画折线。科研训练的有效性、因果归因与 SOTA 比较沿用项目研究协议和 `server-training`，本技能不再另造一套科学判断。

## 公式与算法

- 定义符号、单位、输入输出、维度或张量形状；需要时给具体数值和边界条件。图形状态应对应当前公式步骤，不只播放最终轨迹。
- 区分真实计算与预设轨迹；简化模型说明舍弃了什么。显示精度与计算精度可不同，但不能因舍入制造矛盾。
- 公式可复制、可放大，不用模糊截图代替必要表达。简单表达可用原生文本或合适标记；复杂排版可按实际需求采用本地打包的公式引擎。
- KaTeX／MathJax 等是工具选择，不天然要求联网。若采用，完整随附所需脚本、样式、字体和扩展并验证离线行为，不能照抄在线 CDN 例子后声称离线可用。[KaTeX 浏览器文档](https://katex.org/docs/browser.html)

## SVG、Canvas 与图像

- 结构、标签和少量可交互元素优先考虑便于定位与核对的 DOM／SVG；大量图元或连续绘制按性能需要考虑 Canvas，并提供必要的文字或数据替代。
- 科学图表和数学关系来自真实数据或明确算法，不用生成式插图伪造数值关系。示意插图可以帮助解释，但须保持概念正确并标明性质。
- 图像是否必要由学习目标决定。布局、背景和装饰不应挤占证据、核心图或推理的空间；保持美观可以服务可读性，无需机械清除所有视觉修饰。
