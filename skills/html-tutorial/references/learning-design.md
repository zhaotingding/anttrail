# 学习目标、知识密度与自主节奏

适用：组织新材料、补前置知识、设计阅读路线或理解检查。核心判断已在本地写清，来源链接供核验，不要求每次联网阅读。

## 先确定学习任务

- 用“读完后能解释、预测、比较、诊断或完成什么”描述目标，而不是以页数或图表数量描述成果。识别读者已掌握的内容和最短必要前置链。
- 材料较多时先整理问题、证据、关系、步骤、例子和限制，再决定页面组织。复杂且目标未定的任务先给简要大纲校准；用户已明确授权直接制作时，不再强制第二次确认。
- 内容密度优先提升有用关系和可回查信息，删除无信息开场、重复定义、空洞总结和展示性大横幅。关键推导不能因追求“简短”而消失。

## 三种阅读深度

| 深度 | 适合内容 | 控制方式 |
| --- | --- | --- |
| 概览 | 当前问题、核心关系、结论范围和导航 | 首屏可定位；不让概览占满多个屏幕 |
| 主学习路径 | 关键推理、步骤、图解、对照及解释 | 学习者自主前进、回退或跳转，图文就近 |
| 深入与复查 | 推导、符号、原始数据、来源、边界情况 | 按需展开或锚点定位，不把所有内容默认藏起来 |

这不是固定三页模板。短解释可以同屏完成；长报告也不应把每一段都折叠成一个按钮。已有专家读者可跳过基础内容，初学者能找到前置解释。

分段尤其适合复杂且呈现过快的材料；它是按有意义的推理单元组织，不是机械规定每节五分钟。[Mayer 的分段与一致性原则](https://www.cambridge.org/core/books/multimedia-learning/7A62F072A71289E1E262980CB026A3F9/listing)

## 重要机制的学习闭环

1. 给出一个当前要回答的问题，必要时请读者先预测。
2. 用具体例子、对照或操作观察结果，标明数据性质。
3. 解释结果为何出现，指出限制和常见误解。
4. 用一个不同条件、反例或简短问题检查理解，再给可回查的小结。

按目标选择环节，不要求每章固定五道题或全部选择题。优先检测能否迁移和解释：换参数预测结果、解释两个方案的差异、发现错误推理、在新例子中选择并说明理由。不能只靠原句定位或关键词复述答对。

答案默认可按需显示，反馈说明理由及误解来源，支持重试或直接查看。选项随机化仅在有必要且答案映射同步时使用，不把随机化当学习有效性的证据。不得用测验锁住正文或强迫用户答题。

研究报告可以用“这项结论由哪些证据支持、哪些条件下不能推出”代替测验。检索练习、图文结合及解释性提问有研究依据，但其作用依赖目标和设计，不能声称在所有场景中必然优于排版改善。[IES 学习实践指南](https://ies.ed.gov/ncee/WWC/PracticeGuide/1/Published)

## 查找与持续学习

目录、标题和术语入口应支持找到指定结论及依据；只有内容规模需要时才加全文搜索。先定义要找的问题和读者基础，再做定位检查，不把统一“三分钟”当任何材料的质量门槛。

连续多课或用户确需时，保存阅读位置、重要参数和自测错因；区分“读过”与“掌握”。单页解释不建立完整学习档案、账户或后台。默认本地保存时说明范围及清除方式，在目标打开环境验证后才承诺保存有效。
