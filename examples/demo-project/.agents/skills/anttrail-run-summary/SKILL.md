# 运行用时小报

从项目根运行 `python report.py`，按[字段约定](references/fields.md)解释结果。报告结论时用实际行名和数值，并把本次读过的来源以短链接列出。

如果用户要求保存经验证的口径，先核对字段约定是否已有等价条目。将有证据的新约定写回同一参考，并指出复核它的输入和命令，供下一位 Agent 使用。
