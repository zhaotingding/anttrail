# 用时小报

本目录是一个可以独立复制的小项目。在这里运行 `python report.py` 会读取同目录的虚构数据 `runs.csv`，输出每项已完成任务的用时。需要 Python 3，无第三方依赖。

## 工作约定

- 对普通修改请求，先分析、给出验收办法并等待授权。用户明确要求直接执行时，在批准范围内完成。
- 每轮用简短摘要说明任务和采用的来源。每个 Skill 或参考都用可点击的名称并写明读取状态。`拟用` 表示只有使用计划。`本轮读取` 表示已经读过正文。`沿用已读` 表示先前读过且仍有效。`读取失败` 表示没取得所需内容。打开索引与读到正文是两件事。
- 获准记住经验证的项目经验时，就近更新已有项目 Skill。另一位 Agent 接手时从磁盘或同一分支取得最新版本，核对当前任务的授权。修改前先读最新内容，已有等价约定直接复用。

## 项目 Skill

- [anttrail-run-summary](.agents/skills/anttrail-run-summary/SKILL.md) 适用于生成、解释用时小报，或保存与小报有关的已验证口径。
